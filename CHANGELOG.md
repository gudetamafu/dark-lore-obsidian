# Changelog

## 0.1.2

- Links are underlined in dots with a border instead of a dotted text decoration, so every version of Obsidian shows the dots. Obsidian's directory flagged the old way as only partly supported.

## 0.1.1

The first release of Dark Lore: the tavern at night, and parchment by day.

- IM Fell English for reading, Cinzel Decorative for titles, VT323 for the terminal, all embedded, so no network calls.
- Note boxes amber, info lilac, to-dos gold.
- Needs Obsidian 1.13 or newer. Tested on Obsidian 1.15 on Windows.

To install by hand, put `manifest.json` and `theme.css` in `<your vault>/.obsidian/themes/Dark Lore/`.
